Web Serial Connection Guide

Browser Requirements:

  • Google Chrome (v89+), Microsoft Edge (v89+), or Opera (v75+).
  • The page must run in a secure context: localhost, 127.0.0.1, or https://.

Arduino Uno USB Connection Steps:

  1. Connect your Arduino Uno via USB cable to your computer.
  2. Ensure the Arduino sketch from Arduino/AutoSense.ino is uploaded.
  3. Close the Arduino IDE Serial Monitor so the COM port is free!
  4. Click the blue "Connect Device" button above.
  5. Select the Arduino Uno COM port in the browser popup prompt.
